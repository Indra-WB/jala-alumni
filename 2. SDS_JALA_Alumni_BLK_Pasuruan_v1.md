# Software Design Specification (SDS)

# JALA Alumni BLK Pasuruan

Version: 1.0

## 1. Pendahuluan

Dokumen SDS menjelaskan rancangan teknis aplikasi JALA Alumni BLK
Pasuruan sebagai acuan implementasi.

## 2. Arsitektur Sistem

-   Backend : CodeIgniter 4
-   Frontend : Tailwind CSS
-   Database : MySQL
-   Dual Database Connection

## 7. Desain Login

Input NIK ↓ Cari di Database Lama ↓ Data ditemukan ↓ Cek akun di users ↓
Jika belum ada -\> registrasi Jika ada -\> login
