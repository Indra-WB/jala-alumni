# Product Requirement Document (PRD)

# JALA Alumni BLK Pasuruan

Version: 1.0\
Status: Draft\
Owner: UPT BLK Pasuruan

------------------------------------------------------------------------

# 1. Executive Summary

JALA Alumni BLK Pasuruan adalah portal resmi jejaring alumni yang
berfungsi sebagai media tracer study dan jaringan alumni UPT BLK
Pasuruan. Sistem mengintegrasikan data pelatihan dan penempatan kerja
dari aplikasi yang sudah ada melalui dua koneksi database pada
CodeIgniter 4.

# 2. Latar Belakang

UPT BLK Pasuruan telah memiliki aplikasi yang menyimpan data penempatan
alumni, namun belum tersedia portal alumni yang mampu: - Menghubungkan
alumni. - Menampilkan statistik penempatan kerja. - Memfasilitasi
pembaruan data alumni. - Menjadi media informasi bagi masyarakat.

# 3. Tujuan Produk

-   Mendukung tracer study.
-   Membangun jejaring alumni.
-   Menyediakan dashboard statistik realtime.
-   Menyediakan direktori alumni.
-   Menjadi portal resmi alumni UPT BLK Pasuruan.

# 8. User Journey

## Registrasi

1.  Alumni membuka halaman registrasi.
2.  Memasukkan NIK.
3.  Sistem mencari data pada database lama.
4.  Jika ditemukan, alumni membuat password.
5.  Akun aktif.

## Login

-   NIK + Password.

## Update Status

-   Login.
-   Mengubah status bekerja/wirausaha/belum bekerja.
-   Data diperbarui ke database lama.
-   Audit log tercatat.

# 9. Business Rules

-   Registrasi hanya menggunakan NIK yang valid.
-   Password disimpan hanya di database JALA Alumni.
-   Data pelatihan berasal dari database lama.
-   Status pekerjaan hanya menyimpan pekerjaan saat ini.
-   Dashboard menampilkan data realtime.

# 18. Catatan Arsitektur

Arsitektur menggunakan Dual Database Connection pada CodeIgniter 4.

Database Lama: - Digunakan untuk membaca dan memperbarui data
operasional alumni.

Database Baru: - Digunakan untuk autentikasi, konfigurasi aplikasi,
audit log, konten landing page, dan fitur tambahan.
