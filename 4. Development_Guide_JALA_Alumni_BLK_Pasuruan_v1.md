# Development Guide

# JALA Alumni BLK Pasuruan

Version: 1.0

## 1. Tujuan

Dokumen ini menjadi panduan teknis bagi tim pengembang dalam membangun
aplikasi JALA Alumni BLK Pasuruan menggunakan CodeIgniter 4 dan Tailwind
CSS.

## 2. Technology Stack

-   PHP 8.2+
-   CodeIgniter 4
-   MySQL 8+
-   Tailwind CSS
-   ApexCharts
-   LeafletJS
-   Heroicons

## 3. Struktur Proyek

    app/
     ├── Config/
     ├── Controllers/
     ├── Filters/
     ├── Helpers/
     ├── Libraries/
     ├── Models/
     ├── Services/
     ├── Views/
     └── Database/

    public/
     ├── assets/
     ├── uploads/
     └── index.php

    writable/
    tests/

## 4. Standar Penamaan

-   Controller : PascalCase
-   Model : PascalCase
-   Service : PascalCase
-   Method : camelCase
-   Variable : camelCase
-   Database Table : snake_case
-   Column : snake_case

## 5. Dual Database Configuration

Connection: - default = Database JALA Alumni - training = Database Lama

Gunakan Model/Service yang sesuai untuk setiap koneksi.

## 6. Arsitektur Aplikasi

Presentation Layer ↓ Controller ↓ Service ↓ Model ↓ Database

Hindari business logic pada Controller.

## 7. Struktur Module

Public - Landing - Statistik - Direktori

Authentication - Login - Register - Forgot Password

Alumni - Dashboard - Profil - Status Kerja

Admin - Dashboard - Mitra - Cerita Alumni - Banner - Audit Log

Super Admin - User Management - Role Management - Settings

## 8. Coding Standard

-   PSR-12
-   MVC Pattern
-   Service Layer
-   Reusable Components
-   DRY
-   SOLID (jika memungkinkan)
